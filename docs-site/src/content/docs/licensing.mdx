:::danger[Do not assume SQL Server is free]
The toolkit does not grant SQL Server use rights. Microsoft licenses SQL Server Developer editions for development, testing, and demonstration, not production. SQL Server Express has separate no-cost rights and technical limits. Paid editions, Azure services, Windows, and third-party software can add license and usage obligations. Microsoft's current Product Terms and your agreements are definitive.
:::

## Catalog responsibilities

Before a tool or data source can be automated, its catalog record should identify:

- owner and contributors;
- official project and source links;
- license or commercial terms;
- whether redistribution is permitted;
- whether installation requires acceptance or a separate purchase;
- required attribution;
- version, checksum, and provenance;
- any restrictions on sample or real data.

Open source, source-available, freeware, free tiers, trials, commercial products, public data, and redistributable data are different categories. The UI and reports should preserve those distinctions.

## Candidate versus distributed dependency

A project listed in the roadmap or community catalog is a **candidate**. It becomes a distributed or downloaded dependency only when an implementation explicitly integrates it. Release-specific [Third-party Notices](../third-party-notices/) will record that difference.

The older Azure SQLVM Toolkit has its own [third-party notices](https://kaysauter.github.io/azure-sqlvm-toolkit/third-party-notices/). Those notices do not describe dependencies of this new repository.
