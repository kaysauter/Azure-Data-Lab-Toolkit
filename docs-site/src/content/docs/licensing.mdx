## SQL Server editions

The direct [SQL Server 2025 Developer, Express, and Evaluation license terms](https://www.microsoft.com/content/dam/microsoft/usetm/documents/sql-server/sql-server-2025-developer%2C-express%2C-evaluation/retail/SQL_Server_2025_Developer_Express_and_Evaluation_Edition_English.pdf) distinguish the editions:

- **Developer** permits design, development, test, and demonstration use, but not production use.
- **Express** is a separate no-cost edition with its own use and distribution rights. It is not merely "Developer for production." Its technical capacity and feature limits must be checked in the current [editions and supported-features documentation](https://learn.microsoft.com/en-us/sql/sql-server/editions-and-components-of-sql-server-2025).
- **Evaluation** is time-limited evaluation software and is not licensed for production.
- **Standard and Enterprise** deployments require an applicable paid, pay-as-you-go, subscription, or bring-your-own-license route.

Start every SQL licensing decision with [Microsoft Product Terms](https://www.microsoft.com/licensing/terms/) and [SQL Server licensing guidance](https://www.microsoft.com/licensing/guidance/SQL). A label such as "lab," "demo," or `ContainsSensitiveData: false` does not establish licensing rights.

## Azure and Fabric charges

No-cost software rights do not make the surrounding lab free. Compute, Windows, storage, networking, Bastion, monitoring, backup, data transfer, and other services can be chargeable.

Check the current service and agreement terms together with the relevant pricing pages:

- [SQL Server on Azure Virtual Machines pricing guidance](https://learn.microsoft.com/en-us/azure/azure-sql/virtual-machines/windows/pricing-guidance)
- [Windows Virtual Machines pricing](https://azure.microsoft.com/en-us/pricing/details/virtual-machines/windows/)
- [Azure SQL Database pricing](https://azure.microsoft.com/en-us/pricing/details/azure-sql-database/)
- [Microsoft Fabric pricing](https://azure.microsoft.com/en-us/pricing/details/microsoft-fabric/)
- [Azure Bastion pricing](https://azure.microsoft.com/en-us/pricing/details/azure-bastion/)

Azure Hybrid Benefit, Visual Studio subscription benefits, reservations, savings plans, and organization-specific discounts have eligibility rules. The toolkit's future cost report will show assumptions but will not determine entitlement.

## Third-party tools and data

Open source, source-available, freeware, free tiers, trials, commercial products, public data, and redistributable data are different categories. Before the toolkit can automate an item, its catalog record needs:

- owner, contributors, and authoritative project link;
- license or commercial terms and the applicable version;
- redistribution and download permissions;
- purchase, account, or acceptance requirements;
- attribution and notice requirements;
- data-source rights and restrictions;
- version, checksum, provenance, and installed evidence.

A roadmap entry is a candidate, not a bundled dependency and not permission to redistribute it. Release-specific [Third-party Notices](../third-party-notices/) will identify what a release actually downloads, installs, or distributes.

The older Azure SQLVM Toolkit has separate [third-party notices](https://kaysauter.github.io/azure-sqlvm-toolkit/third-party-notices/). They do not grant rights for this repository or its future catalog.
